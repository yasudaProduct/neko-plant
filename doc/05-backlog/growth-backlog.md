# 本番運用バックログ

本番運用を本格化し、ユーザーを増やすための作業リスト。
UIの見た目・操作性の改善候補は [ui-improvement-backlog.md](./ui-improvement-backlog.md) にあります。

方針の背景は [../04-operations/analytics.md](../04-operations/analytics.md) と
[../04-operations/monitoring.md](../04-operations/monitoring.md) を参照してください。

## 優先順位の考え方

**穴を塞ぐ → 見えるようにする → 増やす**、の順です。
計測がないまま集客すると、伸びなかったときに理由が分かりません。
通報機能がないまま人を増やすと、不適切な投稿に手作業で対応することになります。

## 1. 足元を固める（着手中）

| # | 項目 | 状態 |
| --- | --- | --- |
| G1 | `/api/health` と外形監視 | 実装済み。**監視サービスの登録が未** |
| G2 | サーバーエラーの Webhook 通知 | 実装済み。**`ERROR_WEBHOOK_URL` の設定が未** |
| G3 | DBの定期バックアップ | ワークフロー実装済み。**`BACKUP_GPG_PASSPHRASE` の設定と復元テストが未** |
| G4 | Search Console 登録とサイトマップ送信 | メタタグ実装済み。**登録作業が未** |
| G5 | Supabase のプラン確認（自動バックアップの有無） | 未 |

## 2. 見えるようにする

| # | 項目 | 内容 |
| --- | --- | --- |
| G6 | `/admin` の週次指標 | 投稿・ユーザー・いいねの週次推移。累計だけでは変化が見えない |
| G7 | `/admin` のコホート転換率 | 登録 → 猫登録 → 初投稿 → 再投稿。定義は analytics.md |
| G8 | GA4 イベント | 投稿フローの離脱、検索語、検索0件、シェア押下 |
| G9 | AI判定の採用率 | **スキーマ変更が必要**。判定結果の記録と、タグの由来（ai / manual）を持つ |

G9 は `plant_identification_logs` に結果列を足し、`post_plants` に `source` を持たせる案です。
マイグレーションと `supabase/tests/01_rls_structure.sql` の更新がセットになります
（[../04-operations/database.md](../04-operations/database.md)）。

## 3. 人を増やす前に必要なもの

| # | 項目 | 内容 |
| --- | --- | --- |
| G10 | 通報機能 | 投稿の通報 → `/admin` で確認 → 非表示。現在は承認も通報もなく、対応はDB直編集 |
| G11 | 投稿のレート制限 | AI判定にはあるが、投稿そのものには無い。連投による荒らしを止められない |
| G12 | 退会・削除の動作確認 | 本番データで一度通しておく。Storage の残骸も確認する |

**G10 は人を集める前にやるべきです。** UGCのサービスで通報導線がないのは、
問題が起きてからでは遅い種類の欠落です。

## 4. 増やす

| # | 項目 | 内容 |
| --- | --- | --- |
| G13 | 初期データの投入 | 自分と身近な人で30〜50投稿・30種程度。「実績の多い植物」枠が空だと初見に響かない |
| G14 | シェア導線 | 投稿詳細と植物ページに X / LINE の共有ボタン。OGPは既にあるので実装は小さい |
| G15 | SNS運用 | `@neko_plant` の定常投稿。投稿されたものを紹介する形が続けやすい |
| G16 | 外部毒性データの併記 | ASPCA等の情報を「外部情報」として明示。投稿ゼロの植物ページに価値が出る |

**G16 は製品判断が必要です。** ポジティブリスト方式（危険と断定しない）との整合を、
表示の文言と出典の明示でどう取るかを先に決めてください
（[../01-product/service-description.md](../01-product/service-description.md) §5.2 に拡張余地として記載あり）。

検索流入はこのサービス最大の入口になりえます。「植物名 + 猫」で調べる人は継続的にいるためです。
ただし投稿ゼロの植物ページは「情報がありません」しか言えず、いま検索結果で戦えません。
G13 と G16 は、どちらもこの弱点に効きます。

## やらないこと（現時点）

| 項目 | 理由 |
| --- | --- |
| A/Bテスト | 週の投稿数が2桁のうちは差が検出できない。インタビューのほうが速い |
| 広告出稿 | 受け皿（コンテンツ量と通報導線）が整っていない |
| 新しい計測SaaSの追加 | GA4 とDB集計で足りる。CSPとプライバシーポリシーの更新コストに見合わない |
